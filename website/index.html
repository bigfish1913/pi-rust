01 / WHY RPI

从一条 prompt，
长出完整系统。

Agent 不应该被锁在一个 CLI 里。rpi 把模型、循环、工具、会话和终端体验拆成可以独立替换的 Rust 层，让你从最小实验开始，逐步长成自己的产品。

02 / ARCHITECTURE

每一层都有自己的边界。

从 Provider 到 CLI，单向依赖让核心库保持轻盈，也让你的扩展有明确的落点。

先跑起来，
再加复杂度。

06 / GET STARTED

你的 Agent，
从这里开始。

想直接使用 CLI 就安装 rpi-cli；想研究 Agent loop，再拉源码运行 faux provider。

安装预编译二进制（无需 Rust 工具链）
$curl -fsSL https://raw.githubusercontent.com/bigfish1913/pi-rust/main/scripts/install.sh | sh
直接安装 CLI
$cargo install rpi-cli
从源码运行示例
$git clone https://github.com/bigfish1913/pi-rust.git && cd pi-rust && cargo run -p minimal
